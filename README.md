# 🎬 Movie Recommender — Deep Learning (Embedding + Attention)

A content-based movie recommender that reads a movie's plot description, turns it into a
"meaning vector" using an Embedding + Attention neural network, and recommends similar
movies using cosine similarity — no user history required.

## How It Works

1. **Data cleaning** — parse genres, drop missing overviews (`tmdb_5000_movies.csv` → ~4,771 movies)
2. **Tokenization** — text turned into padded integer sequences (Keras `Tokenizer`)
3. **Embedding layer** — each word becomes a learned vector of numbers
4. **Attention layer** — learns which words in the plot matter most
5. **Pooling + Dense + Softmax** — combines word vectors into one "meaning vector" per movie,
   trained to predict genre as a proxy task
6. **Cosine similarity** — the meaning vectors (not the genre prediction) are compared to
   rank similar movies
7. **Streamlit app** — pick a movie, get top 5 recommendations

> Note: This model is trained on ~4,800 movies with no pretrained word vectors, so
> recommendations lean heavily on genre rather than fine-grained plot nuance — a known
> limitation of small-data, from-scratch embeddings (see notebook for details).

## Setup

```bash
# 1. Create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt
```

## Usage

**Step 1 — Run the notebook** (`app.ipynb`) top to bottom.
This cleans the data, trains the model, and saves:
`movie_model.keras`, `tokenizer.pkl`, `movie_data.pkl`

**Step 2 — Launch the app:**
```bash
streamlit run app.py
```
Opens at `http://localhost:8501`. Pick a movie from the dropdown, click **Recommend**.

## Dataset

[TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) — place
`tmdb_5000_movies.csv` in the project root before running the notebook.

## Tech Stack

- **TensorFlow / Keras** — Embedding, Attention, Dense layers
- **scikit-learn** — train/test split, label encoding, cosine similarity
- **pandas / numpy** — data handling
- **Streamlit** — web app UI
